# Frontend do FlowCore

Aplicação Angular 22.2.0. Consulte o [README principal](../README.md) para conhecer o estado da entrega, preparar o ambiente e executar os testes e o build.

Nesta pasta, os scripts disponíveis são:

| Comando | Finalidade |
| --- | --- |
| `npm start` | Iniciar o servidor de desenvolvimento. |
| `npm test -- --watch=false` | Executar os testes uma vez. |
| `npm run build` | Gerar o build da aplicação. |

No PowerShell, também é possível usar `npm.cmd`.
